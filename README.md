# 🏎️ Street Racing

Мобильная 3D-гоночная игра для Android, создаваемая на Kotlin с использованием Android SDK и OpenGL ES.

## Текущий этап: 0.1.0
- [x] Создан Android-проект на Kotlin
- [x] Настроено игровое окно на OpenGL ES 2.0
- [x] Добавлен базовый цикл рендеринга
- [ ] Камера и игровая сцена
- [ ] Управление автомобилем
- [ ] Базовая физика автомобиля
- [ ] Собственная 3D-модель SR-01
- [ ] Первая игровая сборка APK

## Первый автомобиль: SR-01
- Красный спортивный седан
- Собственный дизайн
- Сочетание агрессивного и премиального стиля

## Технологии
- Kotlin
- Android SDK
- OpenGL ES 2.0
- Gradle
- GitHub Actions

## Сборка
APK автоматически собирается через GitHub Actions при push в ветку `main`.
Готовый APK будет доступен в разделе **Actions → Artifacts**.
